## Project Overview

This project aims to recreate Union Pacific Big Boy No. 4005 in three different configurations:

- **NEW 1941:** Original factory configuration as delivered in 1941.
- **Post-Accident:** Reconstruction of No. 4005 following its historical accident.
- **Oil-Fired:** A diesel-fueled steam locomotive variant.

The project involves historical research, AI-assisted development, manual 3D modeling, mechanical detailing, and future adaptations for Railroader and Derail Valley.

The goal is to create detailed and historically grounded models while documenting the development process.
